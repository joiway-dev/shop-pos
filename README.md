# ระบบหน้าร้าน + หลังบ้าน ร้านวัสดุก่อสร้าง

ระบบขายหน้าร้านและจัดการร้าน ทำงานบนเครื่องของร้าน ไม่ต้องใช้อินเทอร์เน็ต

## สำหรับร้านค้า: เปิดใช้งาน
1. ต้องมี Python 3.13 ในเครื่อง (ติดตั้งครั้งเดียว)
2. ดับเบิลคลิก `scripts\start.bat` — ครั้งแรกจะติดตั้งโปรแกรมให้เอง (ต้องต่อเน็ตครั้งแรกครั้งเดียว)
3. เบราว์เซอร์จะเปิดที่ http://localhost:8000 เอง
4. **ห้ามปิดหน้าต่างสีดำ** ระหว่างใช้งาน

เครื่องอื่นในร้าน (วง LAN เดียวกัน) เข้าได้ที่ `http://<IP เครื่องหลัก>:8000`

ลืม PIN เจ้าของร้าน → ดับเบิลคลิก `scripts\reset_owner_pin.bat` ที่เครื่องหลัก

## สำหรับนักพัฒนา: ทำงานหลายเครื่อง
ข้อมูลร้าน (`data/`) ไม่อยู่ใน git — มีเฉพาะโค้ด

**เครื่องใหม่ (ครั้งแรก)**
```
git clone <URL ของ repo> shop
cd shop
scripts\dev_setup.bat
```

**ก่อนเริ่มงานทุกครั้ง** — `git pull` แล้ว `scripts\dev_setup.bat` (ติดตั้งแพ็กเกจใหม่ + migrate + รัน test)

**ก่อนลุกจากเครื่อง** — `git add -A`, `git commit`, `git push` (งานที่ยังไม่ push จะดึงจากเครื่องอื่นไม่ได้)

สถานะงานแต่ละเฟสและการตัดสินใจทั้งหมดอยู่ใน `CLAUDE.md` / `SPEC.md`

## ทดสอบด้วยมือ — เฟส 0
1. ลบไฟล์ `data\shop.db` (ถ้ามี) แล้วเปิด `scripts\start.bat` → ต้องเจอหน้า "ตั้งค่าครั้งแรก"
2. กรอกชื่อ + PIN 4 หลักสองช่องให้ **ไม่ตรงกัน** → ต้องขึ้น "PIN ทั้งสองช่องไม่ตรงกัน"
3. กรอกให้ตรงกัน → เข้าหน้า "ตั้งค่าร้าน" อัตโนมัติ
4. กรอกชื่อร้าน เลือก "จด VAT" แต่ไม่ใส่เลขผู้เสียภาษี → กดบันทึก ต้องขึ้นข้อความสีแดง
5. ใส่เลขผู้เสียภาษีจริงของร้าน → บันทึกได้ ขึ้น "บันทึกเรียบร้อยแล้ว"
6. เลือก "สาขา" ใส่เลข 3 → บันทึก แล้วเปิดหน้าใหม่ ต้องเห็น 00003
7. อัปโหลดโลโก้ (PNG/JPG) → เห็นรูปตัวอย่าง
8. กด "ออกจากระบบ" → หน้าเลือกชื่อ กดเลข 1 บนคีย์บอร์ด → ใส่ PIN → Enter → เข้าหน้าหลัก
9. ใส่ PIN ผิด → ต้องขึ้น "PIN ไม่ถูกต้อง", กด Esc → กลับไปหน้าเลือกชื่อ
10. เมนู "ผู้ใช้งาน" → เพิ่มพนักงานขาย 1 คน (PIN 4 หลัก) → ออกจากระบบ → ต้องเห็นชื่อพนักงานในหน้าเลือกชื่อ
11. เข้าเป็นพนักงาน → ต้อง **ไม่เห็น** เมนูตั้งค่าร้าน/ผู้ใช้งาน, พิมพ์ http://localhost:8000/settings เอง → ต้องขึ้น "ไม่มีสิทธิ์"
12. ออกจากระบบ เลือกพนักงาน ใส่ PIN ผิด 5 ครั้ง → ครั้งต่อไปต้องขึ้น "ระบบล็อกชั่วคราว" แม้ใส่ PIN ถูก
13. เข้าเป็นเจ้าของร้าน → หน้าผู้ใช้งาน พนักงานคนนั้นขึ้น "ล็อก" → กด "ปลดล็อก" → พนักงานเข้าได้ทันที
14. หน้าผู้ใช้งาน กด "ปิดใช้งาน" พนักงาน → ชื่อต้องหายจากหน้าเลือกชื่อ; ปุ่มปิดใช้งานของตัวเองต้องไม่มี
