# ระบบหน้าร้าน + หลังบ้าน ร้านวัสดุก่อสร้าง

ระบบขายหน้าร้านและจัดการร้าน ทำงานบนเครื่องของร้าน ไม่ต้องใช้อินเทอร์เน็ต

## สำหรับร้านค้า: เปิดใช้งาน
1. ต้องมี Python 3.13 ในเครื่อง (ติดตั้งครั้งเดียว)
2. ดับเบิลคลิก `scripts\start.bat` — ครั้งแรกจะติดตั้งโปรแกรมให้เอง (ต้องต่อเน็ตครั้งแรกครั้งเดียว)
3. เบราว์เซอร์จะเปิดที่ http://localhost:8000 เอง
4. **ห้ามปิดหน้าต่างสีดำ** ระหว่างใช้งาน

เครื่องอื่นในร้าน (วง LAN เดียวกัน) เข้าได้ที่ `http://<IP เครื่องหลัก>:8000`

ลืม PIN เจ้าของร้าน → ดับเบิลคลิก `scripts\reset_owner_pin.bat` ที่เครื่องหลัก

## สำหรับนักพัฒนา: ทำงานหลายเครื่อง
ข้อมูลร้าน (`data/`) ไม่อยู่ใน git — มีเฉพาะโค้ด

**เครื่องใหม่ (ครั้งแรก)**
```
git clone <URL ของ repo> shop
cd shop
scripts\dev_setup.bat
```

**ก่อนเริ่มงานทุกครั้ง** — `git pull` แล้ว `scripts\dev_setup.bat` (ติดตั้งแพ็กเกจใหม่ + migrate + รัน test)

**ก่อนลุกจากเครื่อง** — `git add -A`, `git commit`, `git push` (งานที่ยังไม่ push จะดึงจากเครื่องอื่นไม่ได้)

สถานะงานแต่ละเฟสและการตัดสินใจทั้งหมดอยู่ใน `CLAUDE.md` / `SPEC.md`

## ทดสอบด้วยมือ — เฟส 0
1. ลบไฟล์ `data\shop.db` (ถ้ามี) แล้วเปิด `scripts\start.bat` → ต้องเจอหน้า "ตั้งค่าครั้งแรก"
2. กรอกชื่อ + PIN 4 หลักสองช่องให้ **ไม่ตรงกัน** → ต้องขึ้น "PIN ทั้งสองช่องไม่ตรงกัน"
3. กรอกให้ตรงกัน → เข้าหน้า "ตั้งค่าร้าน" อัตโนมัติ
4. กรอกชื่อร้าน เลือก "จด VAT" แต่ไม่ใส่เลขผู้เสียภาษี → กดบันทึก ต้องขึ้นข้อความสีแดง
5. ใส่เลขผู้เสียภาษีจริงของร้าน → บันทึกได้ ขึ้น "บันทึกเรียบร้อยแล้ว"
6. เลือก "สาขา" ใส่เลข 3 → บันทึก แล้วเปิดหน้าใหม่ ต้องเห็น 00003
7. อัปโหลดโลโก้ (PNG/JPG) → เห็นรูปตัวอย่าง
8. กด "ออกจากระบบ" → หน้าเลือกชื่อ กดเลข 1 บนคีย์บอร์ด → ใส่ PIN → Enter → เข้าหน้าหลัก
9. ใส่ PIN ผิด → ต้องขึ้น "PIN ไม่ถูกต้อง", กด Esc → กลับไปหน้าเลือกชื่อ
10. เมนู "ผู้ใช้งาน" → เพิ่มพนักงานขาย 1 คน (PIN 4 หลัก) → ออกจากระบบ → ต้องเห็นชื่อพนักงานในหน้าเลือกชื่อ
11. เข้าเป็นพนักงาน → ต้อง **ไม่เห็น** เมนูตั้งค่าร้าน/ผู้ใช้งาน, พิมพ์ http://localhost:8000/settings เอง → ต้องขึ้น "ไม่มีสิทธิ์"
12. ออกจากระบบ เลือกพนักงาน ใส่ PIN ผิด 5 ครั้ง → ครั้งต่อไปต้องขึ้น "ระบบล็อกชั่วคราว" แม้ใส่ PIN ถูก
13. เข้าเป็นเจ้าของร้าน → หน้าผู้ใช้งาน พนักงานคนนั้นขึ้น "ล็อก" → กด "ปลดล็อก" → พนักงานเข้าได้ทันที
14. หน้าผู้ใช้งาน กด "ปิดใช้งาน" พนักงาน → ชื่อต้องหายจากหน้าเลือกชื่อ; ปุ่มปิดใช้งานของตัวเองต้องไม่มี

## ทดสอบด้วยมือ — เฟส 1 (สินค้า + ระบบจับคู่)
1. เข้าเป็นเจ้าของร้าน → เมนู "สินค้า" → "นำเข้าจาก Excel" → ดาวน์โหลดไฟล์ Excel ตัวอย่าง
2. เปิดไฟล์ดูแผ่น "วิธีกรอก" แล้วอัปโหลดไฟล์ตัวอย่างนั้นกลับเข้าไป → ต้องเห็น "เพิ่มใหม่ 3" และยังไม่บันทึก
3. กด "ยืนยันนำเข้า" → หน้าสินค้าต้องมี 3 รายการ (ปูนเสือ, เหล็ก 12 มม., ทรายหยาบ) พร้อมราคาทุกหน่วย
4. เปิดสินค้าปูนเสือ → กด "+ เพิ่มหน่วย" ใส่ "ครึ่งพาเลท" = 20, ราคา 2850 และแก้ราคาถุงเป็น 150 → บันทึก → ต้องเห็นครบ 3 หน่วย
5. ในหน้าเดียวกัน เพิ่มชื่อเรียก "ปูนตราเสือ" → ต้องขึ้นในรายการชื่อเรียก
6. เมนู "ทดสอบจับคู่" → พิมพ์ `ปูน เสือ` → ต้องขึ้น "✓ ลงบิลได้ทันที"
7. พิมพ์ `ปูนซีเมนต์` → ต้องขึ้น "ต้องเลือก" พร้อมรายการให้เลือก → กด "เลือก" (ติ๊ก "จำคำนี้ไว้") → ขึ้น "จำไว้แล้ว" → ลบคำแล้วพิมพ์ใหม่ → ต้องเป็น ✓
8. ช่อง "วางรายการหลายบรรทัด" (กด F4) วางข้อความนี้แล้วกด "ตรวจรายการ":
   ```
   สวัสดีค่ะ
   ปูนเสือ 10 ถุง
   เหล็ก 12 มิล 20 เส้น
   ทราย 2 ถุง
   ```
   ต้องเห็น: สวัสดีค่ะ = ข้าม / ปูนเสือ 10 ถุง = ✓ / เหล็ก **20 เส้น** (ไม่ใช่ 12) = ✓ / ทราย 2 ถุง = "ต้องเลือก" (ทรายขายเป็นคิว) และปุ่ม "ลงบิล" กดไม่ได้
9. แก้บรรทัดสุดท้ายเป็น `ทราย 2 คิว` แล้วตรวจใหม่ → ปุ่ม "ลงบิล" ต้องกดได้
10. เมนู "ชื่อเรียก" → เลือก "เรียนรู้จากการขาย" → ต้องเห็นคำ "ปูนซีเมนต์" จากข้อ 7 → ลองกดลบ
11. เข้าเป็นพนักงาน → เมนู "สินค้า" ต้องดูได้แต่ **ไม่มี** คอลัมน์ต้นทุน และไม่มีปุ่มเพิ่ม/แก้ไข

## ทดสอบด้วยมือ — เฟส 2 (ขายหน้าร้าน + พิมพ์)
**ร้านไม่จด VAT**
1. เมนู "ขายหน้าร้าน" → กดการ์ดสินค้า 2 ครั้ง → บิลด้านขวาต้องมี 2 ถุง ยอดรวมถูก
2. กด F2 พิมพ์ `ทราย` แล้ว Enter → ทรายเข้าบิล (ถ้าขึ้นรายการให้เลือก ใช้ ↑ ↓ แล้ว Enter)
3. กด F4 วาง `เหล็ก 12 มิล 20 เส้น` → กด "แปลงเป็นรายการสินค้า" → "ตรวจแล้ว เพิ่ม…ลงบิล"
4. ในบิล เปลี่ยนหน่วยปูนเป็น "พาเลท" → ราคาต้องเปลี่ยนเป็นราคาพาเลท
5. กด F9 → ใส่รับเงิน 20000 → เงินทอนต้องถูก → กด Enter → ต้องขึ้น "บันทึกการขายแล้ว" เลขที่ RC…-0001
6. กด "พิมพ์ใบเสร็จ 80 มม." → หน้าพิมพ์เปิดขึ้น (ต้อง **ไม่มี** คำว่า "ภาษี") → ลองพิมพ์ด้วยเครื่องพิมพ์จริง
7. เมนู "บิลขาย" → เปิดบิลนั้น → กด "พิมพ์ A4" → ต้องมีตรา "สำเนา" (เพราะพิมพ์ครั้งที่ 2)
8. ในหน้าบิล ยกเลิกบิล: ใส่เหตุผล + PIN ผิด → ต้องไม่ยอม / PIN ถูก → บิลเป็น "ยกเลิก" สต็อกกลับคืน (ดูที่การ์ดสินค้า)
9. กด "ออกใบใหม่แทน" → หน้าขายมีรายการเดิมพร้อมป้าย "ออกใบใหม่แทน…" → รับเงิน → บิลเก่าต้องมีลิงก์ "ดูบิลใหม่"
10. เข้าเป็นพนักงาน → ใส่ส่วนลด `5%` → ตอนรับเงินต้องขอ PIN เจ้าของร้าน
11. กด "+ ลูกค้าอีกคน" → เปิดบิลที่ 2 ได้ บิลแรกยังอยู่ (พักบิล)

**ร้านจด VAT** (ตั้งค่าร้าน → จด VAT + เลขผู้เสียภาษี)
12. ขายโดยไม่กรอกผู้ซื้อ → ต้องขึ้นให้กรอกชื่อและที่อยู่ผู้ซื้อ
13. กรอกผู้ซื้อ → ได้เลขที่ INV… → พิมพ์ A4 ต้องมี "ใบกำกับภาษี/ใบเสร็จรับเงิน" ต้นฉบับ+สำเนา, ยอดก่อนภาษี, VAT 7%
14. เปิด "ใบกำกับภาษีอย่างย่อ" ในตั้งค่า → ขายแบบไม่กรอกผู้ซื้อได้ เลขที่ ABB…
15. **ให้นักบัญชีตรวจรูปแบบใบกำกับภาษีก่อนใช้งานจริง**
